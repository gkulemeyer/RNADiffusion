# Legacy Archive

This directory stores materials migrated from the repository root that are not
part of the maintained runtime.

- `notebooks_root/` contains legacy notebooks from the old root project.
- `notebooks_app/` contains archived notebooks copied from the refactor branch.
- `other_methods/` contains comparison/reference artifacts.
- `profiler/` contains legacy profiling outputs and helpers.

The canonical application now lives in the repository root and should be run
from there.

Archived notebooks may retain stale paths from historical layouts. They are
kept as reference snapshots and are not part of the maintained runtime.
